# 🤖 Job AI — بوت عروض العمل على واتساب (بدون أي API خارجي)

بوت ذكي يستخرج أحدث عروض العمل تلقائياً من **أنابيك ANAPEC** و **الوظيفة ماروك Alwadifa-Maroc** وينشرها بشكل منسّق واحترافي في مجموعتك على واتساب، مع **لوحة تحكم عربية كاملة**.

## ✅ لماذا هذا الحل جذري ومجاني؟

| المشكلة | الحل |
|---|---|
| لا تملك WhatsApp API | نستخدم **Baileys** — مكتبة مفتوحة المصدر تربط البوت بواتسابك عبر QR تماماً مثل WhatsApp Web. مجانية 100% ولا تحتاج أي تسجيل أو API |
| موقع ANAPEC يعمل بـ Angular | دعم مزدوج: HTTP مباشر + وضع **Chromium headless** الاختياري |
| لا تريد خادماً مدفوعاً | يعمل كاملاً على **هاتفك عبر Termux** |

## 🚀 التثبيت على Termux (خطوة بخطوة)

```bash
# 1. استنساخ المشروع
pkg install git -y
git clone https://github.com/xhackerblack/job-ai-whatsapp.git
cd job-ai-whatsapp

# 2. التثبيت
bash install.sh

# 3. التشغيل
bash start.sh
```

## 📱 أول تشغيل

1. سيظهر **رمز QR** في Termux — افتح واتساب ← الأجهزة المرتبطة ← ربط جهاز ← امسحه
2. افتح المتصفح على: **http://localhost:3000**
3. من تبويب "الاتصال": اختر **مجموعة النشر المستهدفة**
4. اضغط **"فحص المواقع الآن"** — ستُرسل العروض الجديدة تلقائياً للمجموعة

## ⚙️ مميزات لوحة التحكم

- 📊 إحصائيات حية (إجمالي / مرسل / معلّق / آخر فحص)
- 📱 حالة اتصال واتساب + عرض QR داخل اللوحة
- 👥 اختيار مجموعة النشر من مجموعاتك الحقيقية
- 🔍 فحص يدوي + إرسال العروض المعلّقة
- ⏰ فحص تلقائي مجدول (قابل للتخصيص)
- 🔑 فلترة بالكلمات المفتاحية (مثال: تقني، محاسب، سائق)
- 🌐 تفعيل/تعطيل كل مصدر على حدة
- 🖥️ وضع Chromium لموقع أنابيك

## 🛡️ نصائح لتجنب حظر واتساب

- لا تضبط الفحص على أقل من **15 دقيقة**
- أبقِ "أقصى عدد عروض في الدفعة" على **10 أو أقل** (يوجد تأخير ثانيتين بين كل رسالة مدمج في الكود)
- استخدم رقماً ثانوياً للبوت إن أمكن

## 📁 بنية المشروع

```
job-ai-whatsapp/
├── src/
│   ├── index.js      ← نقطة التشغيل والجدولة
│   ├── scraper.js    ← استخراج أنابيك + الوظيفة ماروك
│   ├── whatsapp.js   ← بوت Baileys
│   ├── server.js     ← خادم API للوحة التحكم
│   └── store.js      ← تخزين JSON (عروض + إعدادات)
├── public/index.html ← لوحة التحكم العربية
├── data/             ← البيانات وجلسة واتساب (تُنشأ تلقائياً)
├── install.sh        ← التثبيت بضغطة واحدة
└── start.sh          ← التشغيل
```

## ❓ مشاكل شائعة

| المشكلة | الحل |
|---|---|
| QR لا يظهر في اللوحة | موجود أيضاً في Termux مباشرة — امسحه من هناك |
| أنابيك لا يُرجع عروضاً | فعّل "أنابيك عبر Chromium" من الإعدادات بعد: `pkg install tur-repo && pkg install chromium` |
| تم تسجيل خروج واتساب | زر "فصل وإعادة الربط" في اللوحة ثم أعد التشغيل |
| `node: command not found` | نفّذ: `pkg install nodejs-lts` |
