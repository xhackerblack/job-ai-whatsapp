# 🤖 Job AI WhatsApp Bot — بوت عروض العمل للواتساب

بوت واتساب **مجاني 100% بدون أي API خارجي** يجمع أحدث عروض العمل من **الوظيفة ماروك** و**أنابيك ANAPEC** وينشرها تلقائياً في مجموعة واتساب بشكل احترافي، مع لوحة تحكم ويب كاملة.

## ✨ المميزات (v3)

- 🔍 **فحص تلقائي** لموقعي Alwadifa-Maroc.com و ANAPEC (عناوين، مؤسسات، مدن، عقود، **آخر أجل الترشيح**)
- 🖼️ **صورة متحركة GIF** ترسل مع كل عرض عمل جديد
- ⏰ **تنبيهات آخر الأجل** بثلاثة ألوان: 🟢 مبكر / 🟠 قريب (7 أيام) / 🔴 عاجل (يومان) / ⚫ منتهي — كلها قابلة للضبط
- 🖥️ **لوحة تحكم ويب** بخمسة تبويبات: التحكم، إدارة العروض (بحث/حذف/إعادة إرسال)، إحصائيات الأعضاء، توثيق الأوامر، الإعدادات
- 🔐 **أوامر مخفية للأدمن** عبر واتساب تبدأ بـ `/` — الرد يصل في الخاص ولا يراها الأعضاء (`/حالة` `/فحص` `/ايقاف` `/ترتيب` ...)
- 👥 **أوامر عامة للأعضاء** تبدأ بـ `#` (`#احصائياتي` `#المتصدرون` `#عروض`)
- 📊 تتبع تفاعل كل عضو في المجموعة مع ترتيب المتصدرين
- 🛡️ حماية من التكرار + إدارة الرسائل الفاشلة + إيقاف مؤقت
- 📱 يعمل على **Android عبر Termux** بدون حاسوب

## 🚀 التثبيت (Termux)

```bash
pkg install git -y
git clone https://github.com/xhackerblack/job-ai-whatsapp
cd job-ai-whatsapp
bash install.sh
bash start.sh
```

ثم امسح رمز QR بواتسابك (الأجهزة المرتبطة ← ربط جهاز)، وافتح لوحة التحكم على `http://localhost:3000` واختر مجموعة النشر.

## 🔐 الأوامر المخفية (للأدمن فقط)

| الأمر | الوظيفة |
|---|---|
| `/مساعدة` | قائمة الأوامر |
| `/حالة` | حالة البوت الكاملة |
| `/فحص` | فحص المواقع فوراً |
| `/ارسل` | إرسال العروض المعلّقة |
| `/ايقاف` / `/تشغيل` | إيقاف/استئناف البوت |
| `/صورة_تشغيل` / `/صورة_ايقاف` | تفعيل/تعطيل الصورة المتحركة |
| `/تنبيهات_تشغيل` / `/تنبيهات_ايقاف` | تفعيل/تعطيل تنبيهات الأجل |
| `/ترتيب` | ترتيب الأعضاء الكامل |
| `/مجموعات` | قائمة مجموعاتك |
| `/معلقة` | العروض المعلّقة |
| `/مسح_فاشلة` / `/اعادة_الكل` | إعادة الفاشلة / إعادة كل العروض |

> رقم الأدمن يُضبط من لوحة التحكم ← الإعدادات (بالصيغة الدولية بدون +).

## 👥 أوامر الأعضاء (في المجموعة)

`#احصائياتي` · `#المتصدرون` · `#عروض`

## 📁 البنية

```
job-ai-whatsapp/
├── src/
│   ├── index.js        # نقطة التشغيل + الجدولة + تنبيهات الآجال
│   ├── whatsapp.js     # اتصال Baileys + إرسال العروض والـ GIF
│   ├── scraper.js      # استخراج العروض من الموقعين + تحليل الآجال
│   ├── commands.js     # الأوامر المخفية والعامة
│   ├── server.js       # لوحة التحكم API
│   ├── store.js        # تخزين JSON (عروض/إعدادات/إحصائيات)
│   └── assets_embed.js # الصورة المتحركة مدمجة
├── public/index.html   # واجهة لوحة التحكم
├── install.sh          # تثبيت Termux التلقائي
└── start.sh            # التشغيل
```

## ⚠️ ملاحظات

- استخدم رقماً ثانوياً للبوت لتجنب حظر رقمك الرئيسي
- لا تخفض فترة الفحص عن 15 دقيقة
- مجلد `data/` يحتوي جلسة واتساب — لا تشاركه أبداً
